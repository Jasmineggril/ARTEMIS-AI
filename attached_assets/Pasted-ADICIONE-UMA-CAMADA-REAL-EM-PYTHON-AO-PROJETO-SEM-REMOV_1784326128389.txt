ADICIONE UMA CAMADA REAL EM PYTHON AO PROJETO, SEM REMOVER A STACK ATUAL.

OBJETIVO

Manter o frontend React/TypeScript e o backend Express existentes, mas adicionar um serviço Python responsável pelo processamento dos dados, classificação de risco e futura evolução para Machine Learning supervisionado com Scikit-learn.

A arquitetura final deve ficar assim:

Frontend React/TypeScript
→ Backend Express
→ Serviço Python de análise de risco
→ Resultado retornado ao frontend
→ Banco PostgreSQL

Não substituir o Express. O Python deve funcionar como serviço especializado de análise.

1. ESTRUTURA PYTHON

Criar uma pasta:

python_service/

Com a seguinte estrutura:

python_service/
  app.py
  risk_model.py
  schemas.py
  requirements.txt
  tests/
    test_risk_model.py
  data/
  README.md

2. FRAMEWORK

Usar FastAPI, caso seja compatível com o ambiente do Replit.

Dependências mínimas:

fastapi

Não adicionar bibliotecas desnecessárias.

4. MOTOR INICIAL

Nesta primeira versão, implementar em Python o mesmo motor transparente baseado em regras já existente em TypeScript.

Não chamar esse motor de Machine Learning treinado.

Retornar:

"model_type": "transparent-rule-engine"

Adicionar comentário no código:

“Este motor baseado em regras é utilizado para demonstração do fluxo tecnológico em ambiente controlado. A Prova de Valor prevê treinamento, calibração e validação de modelo supervisionado com dados representativos.”

5. PREPARAÇÃO PARA SCIKIT-LEARN

Criar em risk_model.py uma arquitetura que permita futura troca do motor por um modelo Scikit-learn.

Criar classes ou funções separadas:

- validate_input
- normalize_features
- calculate_rule_score
- classify_risk
- explain_factors
- generate_recommendations
- load_ml_model
- predict_with_ml_model

A função load_ml_model deve verificar se existe um arquivo treinado.

Exemplo:

python_service/models/risk_model.joblib

Se o modelo não existir, usar o motor baseado em regras.

Não fingir que existe modelo treinado.

6. MODELO DEMONSTRATIVO SCIKIT-LEARN

Criar, opcionalmente, um script:

python_service/train_demo_model.py

Esse script deve:

- gerar ou carregar um dataset demonstrativo identificado como sintético;
- treinar um modelo simples de classificação;
- salvar métricas;
- salvar o modelo com joblib;
- indicar claramente que o dataset é sintético;
- nunca apresentar essas métricas como validação real.

Criar:

python_service/models/
python_service/results/

Salvar:

risk_model.joblib
metrics.json

No metrics.json, incluir:

- dataset_type: "synthetic_demo"
- model_name
- accuracy
- precision
- recall
- f1_score
- trained_at
- warning

Warning obrigatório:

“Metrics obtained with synthetic demonstration data and not representative of operational performance.”
