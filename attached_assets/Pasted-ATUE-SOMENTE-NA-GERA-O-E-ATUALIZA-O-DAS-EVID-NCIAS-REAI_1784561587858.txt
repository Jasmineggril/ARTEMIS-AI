ATUE SOMENTE NA GERAÇÃO E ATUALIZAÇÃO DAS EVIDÊNCIAS REAIS DE TRL 4.

OBJETIVO

Executar os testes e validações do projeto CERES AI e registrar apenas resultados reais, comprovados por execução, nos seguintes arquivos:

- docs/trl4/final/02_RELATORIO_TESTES_TRL4.md
- docs/trl4/final/05_METRICAS_MODELO_TRL4.md
- docs/trl4/final/06_MATRIZ_RASTREABILIDADE_TRL4.md
- docs/trl4/final/08_CHECKLIST_FINAL_SUBMISSAO.md

Esses documentos serão utilizados para gerar os arquivos enviados no campo:

“Apresente evidências que comprovem o nível de TRL informado.”

O sistema aceita até 5 arquivos, com tamanho máximo de 10 MB por arquivo.

REGRAS OBRIGATÓRIAS

1. Não inventar resultados.
2. Não registrar testes como aprovados sem execução.
3. Não copiar números antigos sem conferência.
4. Não ocultar falhas, warnings ou limitações.
5. Não apresentar métricas de dados sintéticos como desempenho operacional real.
6. Não chamar motor baseado em regras de Machine Learning.
7. Informar claramente quando os dados forem sintéticos, simulados, históricos ou demonstrativos.
8. Utilizar linguagem técnica, objetiva e adequada a uma banca avaliadora.
9. Manter todos os documentos anonimizados:
   - sem nomes pessoais;
   - sem e-mails;
   - sem empresa;
   - sem instituição;
   - sem CNPJ;
   - sem links identificadores.
10. Utilizar o nome neutro:
   “Plataforma Preditiva de Inteligência Ambiental”.

1. EXECUÇÕES OBRIGATÓRIAS
==================================================

Execute os comandos realmente disponíveis no projeto.

Node/TypeScript:

npm install
npm run check
npm run test
npm run test:risk
npm run test:auth
npm run build

Python:

pip install -r python_service/requirements.txt
pytest python_service/tests -v

Caso exista modelo supervisionado:

python python_service/evaluate_model.py

Testar também:

- GET /health
- POST /analyze-risk
- POST /api/risk-analysis

- aprovados;
- falhados;
- ignorados;
- warnings;
- erros;
- versão das principais dependências.

Se algum comando não existir, registrar:

“Comando não disponível no projeto atual.”

Não inventar resultado substituto.
