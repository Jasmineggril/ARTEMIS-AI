# Marca ARTEMIS AI

| Arquivo | Uso |
|---|---|
| `artemis-logo-dark.webp` | Logo oficial original (raster, fundo escuro). Fonte: `attached_assets/brand/artemis-logo-original.webp`. Usar só sobre fundo escuro (ex.: rodapé). |
| `artemis-symbol-on-dark.svg` / `-on-light.svg` | Símbolo detalhado redesenhado em vetor (A, floresta, órbita, satélite, folha). A partir de ~56 px. |
| `artemis-mark-small-on-dark.svg` / `-on-light.svg` | Versão simplificada (A, órbita, folha), legível até 16 px. |
| `../favicon.svg`, `../favicon.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` | Ícones gerados a partir dos vetores. |
| `og-image.png` | Imagem de compartilhamento (1200×630) com a logo original. |

Por que vetor: a logo original só funciona sobre fundo escuro (as árvores verde-escuras somem e a compressão gera ruído ao recortar o fundo) e fica ilegível abaixo de ~64 px. O nome "ARTEMIS **AI**" é renderizado como texto (`ArtemisWordmark`), nítido e acessível; o "AI" usa verde-esmeralda (#047857 em fundo claro, contraste 5,5:1).
